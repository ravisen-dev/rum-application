# Real User Monitoring (RUM) Application
Real User Monitoring (RUM) is a passive performance tracking technique that captures every interaction a real user has with your web or mobile application in production. It provides direct visibility into user experiences and helps identify and fix frontend bugs, slowdowns, and usability pain points.

# Project Structure
- Javascript Library - To be integrated with Frontend web framework as Angular.
- Web API Application - Backend API to fulfill the RUM application API needs.
- Angular RUM Monitoring App - An app with dashboard and pages to visualize the RUM Application data

# Technology stack
- Javsacript library - npm compatiable library developed in typescript
- Web API Application - Dot net core 10 and postgresql
- Angular RUM Monitoring App - Angular application
